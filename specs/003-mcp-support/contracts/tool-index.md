# Public MCP tool index

The authenticated server exposes **66 tools**. This index uses descriptions returned by official SDK discovery. Every call remains subject to current creator access, consent and plan limits. The three former broad names (`update_overlay`, `update_gallery`, `get_overlay_embed`) are internal service contracts and are not callable MCP aliases.
