# Guide interaction contract

Authenticated dashboard: show the checklist by default on first use, and remember minimization. Anchor the HeroUI progress launcher in the bottom-right corner. Keep feedback in the same dock above it and chat on the left. Consent banners/preferences own interaction; guide controls wait or pause without changing consent. Minimize the welcome panel on inactive editor entry/navigation so it cannot cover normal Save controls.

The core four tasks are create/name, source/filters, preview and OBS setup. Appearance, playlists, website installation and exploration are optional. Use HeroUI checkbox controls to request a confirmed skip; persist skipped IDs separately from completed actions. Uncheck to restore. Click an in-progress task to continue at its saved step. Completed actions show a handoff and an explicit next-task button.

Teach real controls with stable data-tour anchors. Initial creation highlights Add Overlay; actual creation owns navigation. Appearance highlights Customize Overlay Style before following the user's click. Source selection and filters are distinct steps. Locked filters remain noninteractive. Normal application Save buttons, labels and disabled states never change for a tour. Guide-only acknowledgement of unchanged defaults belongs in the popover and records a skip.

Copy targets the actual clipboard button. Successful OBS copying advances to setup instructions; Finish setup guide is self-reported instruction completion, not device verification. Website installation copies public iframe code from Tools, followed by external installation instructions; never publish the private OBS URL. Gallery introduction uses the real Galleries tab. Tools/support introductions explain the existing controls and help center without granting functionality consent.

Missing targets, unexpected navigation and unexpected application dialogs yield with recovery. Expected preview/clip-picker dialogs suspend the spotlight and restore it on close. Tab action steps advance when the actual tab becomes selected. Native select/color popovers remain usable. Escape pauses and restores launcher focus. Storage, clipboard and failed server actions do not fabricate completion. Analytics contain only allowlisted journey/task identifiers.
